# Abaqus 三点对齐装配脚本 (align_by_3_points)

通过对齐三个点，快速将 Abaqus 装配体中的一个零件实例精确装配到另一个零件实例上。

## 功能概述

在 Abaqus/CAE 的 Assembly 模块中，指定**移动实例**上的 3 个点（源点 S1/S2/S3）和**固定实例**上的 3 个对应点（目标点 T1/T2/T3），脚本自动计算刚体变换（旋转 + 平移），将移动实例精确对齐到固定实例。

适用于：
- 两个零件的快速定位装配
- 替代手动平移/旋转的繁琐操作
- 基于基准点（Datum Point）的精确对齐
- 批量装配时的重复定位

## 三点对齐原理

源点 S1, S2, S3 定义源局部正交坐标系：

```
x_s = normalize(S2 - S1)
z_s = normalize(x_s × (S3 - S1))
y_s = z_s × x_s
```

目标点 T1, T2, T3 同理定义目标坐标系。

- 旋转矩阵 `R = R_target · R_source^T`
- 平移向量 `t = T1 - R · S1`
- 变换公式 `p' = R · p + t`

## 文件说明

| 文件 | 用途 |
|------|------|
| `align_by_3_points.py` | 脚本版：修改 CONFIG 后通过 File → Run Script 运行 |
| `align_by_3_points_plugin.py` | **GUI 插件版**：安装到 abaqus_plugins 目录，可视化拾取点对齐 |

## GUI 插件版使用（推荐）

### 安装
1. 将 `align_by_3_points_plugin.py` 复制到 Abaqus 插件目录：
   - Windows: `C:\Users\<用户名>\abaqus_plugins\`
   - Linux: `~/abaqus_plugins/`
2. 重启 Abaqus/CAE
3. 菜单：**Plug-ins → Align by 3 Points**

### 操作流程
1. 下拉选择 **Model** 和要移动的 **Moving Instance**
2. 依次点击 **Pick Source 1/2/3**，对话框自动隐藏，在视口中拾取移动件上的三个点，按 Enter/Done 确认
3. 依次点击 **Pick Target 1/2/3**，在视口中拾取固定件上的三个对应点
4. （可选）勾选 **Dry run** 先验证计算结果
5. 点击 **Apply / OK** 执行对齐

### 支持拾取的点类型
- 几何顶点 (Vertex)
- 基准点 (Datum Point)
- 网格节点 (Node)

## 脚本版使用方法

### 方式一：修改 CONFIG 后直接运行
1. 在 Abaqus/CAE 中打开模型，进入 **Assembly** 模块；
2. 用文本编辑器打开 `align_by_3_points.py`，修改 `CONFIG` 字典：

```python
CONFIG = {
    'model_name': 'Model-1',            # 模型名称
    'moving_instance': 'PART-2-1',      # 需要移动的实例名称
    'source_points': [                  # 移动实例上的 3 个点（全局坐标）
        (0.0, 0.0, 0.0),
        (10.0, 0.0, 0.0),
        (0.0, 10.0, 0.0),
    ],
    'target_points': [                  # 固定实例上的 3 个对应点（全局坐标）
        (100.0, 50.0, 0.0),
        (110.0, 50.0, 0.0),
        (100.0, 60.0, 0.0),
    ],
    'dry_run': False,                   # True: 只计算不执行
}
```

3. 在 Abaqus/CAE 中选择 **File → Run Script**，选择本文件。

### 方式二：作为函数导入调用

```python
from align_by_3_points import align_instance

align_instance(
    model_name='Model-1',
    moving_instance='PART-2-1',
    source_points=[(0, 0, 0), (10, 0, 0), (0, 10, 0)],
    target_points=[(100, 50, 0), (110, 50, 0), (100, 60, 0)],
)
```

### 先验证再执行（推荐）

首次使用时建议设置 `'dry_run': True`，脚本会打印变换参数和精度验证，但不实际移动实例。确认无误后再改为 `False` 执行。

## 点坐标输入格式

所有点坐标均为**装配全局坐标系**下的坐标，支持两种格式：

| 格式 | 示例 | 说明 |
|------|------|------|
| 坐标元组 | `(10.0, 5.0, 0.0)` | 直接指定全局坐标 |
| Datum Point 名称 | `'Datum-1'` | 脚本自动读取该基准点的全局坐标 |

> **提示**：在零件上创建 Datum Point 后，在 Assembly 中可以通过 `Query → Datum` 或直接查看其坐标来获取全局坐标值。

## 操作步骤建议

1. **创建基准点**：在两个零件的对应位置分别创建 3 个 Datum Point（例如孔中心、角点、定位销位置）；
2. **获取坐标**：在 Assembly 中查询这 6 个点的全局坐标；
3. **填写 CONFIG**：将坐标填入脚本的 `source_points` 和 `target_points`；
4. **Dry Run 验证**：先设 `dry_run=True` 运行，检查变换后点的误差；
5. **执行对齐**：设 `dry_run=False` 运行，完成装配。

## 注意事项

- 三个源点**不能共线**，三个目标点也**不能共线**；
- 源点与目标点必须**按顺序一一对应**（S1→T1, S2→T2, S3→T3）；
- 移动实例在变换前的位置不影响结果，脚本计算的是绝对变换；
- 本脚本仅做**刚体变换**，不修改零件几何，不创建接触/约束；
- 变换不可逆，执行前建议保存模型副本；
- 兼容 Abaqus 2020 及以上版本（纯 Python 实现，不依赖 numpy）。
